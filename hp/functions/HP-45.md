# HP-45 — Function Set

- **Access:** Primary functions are direct keys. A single gold shift key selects the gold legend printed above each key. RPN entry with ENTER↑. Angle mode (DEG/RAD/GRD) and display mode (FIX/SCI) are gold-shifted, not switches.
- **Approx. count:** ~46 functions (excluding the ten digit keys)
- **Source:** HP-45 Owner's Handbook (Nov 1974), Keyboard Summary and Index (pp. 58–59, PDF pp. 60–61) plus function sections (pp. 16–41, PDF pp. 18–43) — hp/manuals/HP-45.pdf

## Stack & Registers

| Function | Access | Description |
|----------|--------|-------------|
| ENTER↑ | key | Terminates entry and lifts X into the stack |
| x⇄y | key | Exchanges X and Y |
| R↓ | key | Rolls the stack down one position |
| CLx | key | Clears the X register only |
| CLEAR | gold (CLx) | Clears the entire stack and all storage/summation registers |

## Notes
- 4-level RPN stack (X Y Z T) plus a LAST x register; nine storage registers R1–R9.
- Register arithmetic: pressing STO followed by +, −, ×, or ÷ performs the operation between X and the target register, leaving the result in that register.
- The metric conversion keys return a multiplicative conversion constant into the stack; you then multiply or divide to convert either direction.
