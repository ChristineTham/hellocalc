# HP-65 — Function Set

- **Access:** Primary functions are direct keys. Three prefixes: `f` (gold, legend above key), `f⁻¹` (inverse of the gold function), and `g` (blue, legend below key). Two slide switches: OFF–ON and W/PRGM–RUN. Fully programmable (100 steps) with magnetic-card storage.
- **Approx. count:** ~70 functions/operations (excluding the ten digit keys)
- **Source:** HP-65 Owner's Handbook (Jul 1974), Sections 2–4 and function figures 2-1, 3-1, 3-2, 3-3 (pp. 27–100, PDF pp. 31–104) — hp/manuals/HP-65.pdf

## Memory

| Function | Access | Description |
|----------|--------|-------------|
| STO | key | Stores X into addressable register Rn (n = 1–9) |
| RCL | key | Recalls Rn (n = 1–9) into X |
| CLEAR REG | f EEX | Clears all nine addressable registers |

Register arithmetic: STO followed by +, −, ×, or ÷ then a register number performs that operation on the register with X, leaving the result in the register.

## Notes
- Model-specific: many math functions are reachable two ways — the five "window" defaults on keys A–E (f A=1/x, f B=√x, f C=y^x, f D=R↓, f E=x⇄y) duplicate the same functions on the digit keys. Keys A–E are user-redefinable by program.
- Card reader: the magnetic-card slot along the top has no dedicated keys. With the W/PRGM–RUN switch and by passing a card through the slot, programs are recorded to or read from a card; a bad/blank card gives a blinking error.
- 4-level RPN stack (X Y Z T) plus a LAST X register; nine addressable registers R1–R9. R8 is used by DSZ as an index counter, and R9 is used internally by trig, R→P/P→R and the conditional tests.
- Angle mode defaults to decimal degrees and display to FIX 2 at power-on. Flag keys have both a set/test-flying form and, via the alternate prefix, a lower/test-lowered form.
