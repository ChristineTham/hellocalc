# HP-97 — Function Set

- **Access:** single gold `f` prefix (max one shifted function per key); slide switches OFF–ON (power), PRGM–RUN, and TRACE MAN–NORM (print mode); thermal strip printer with paper-advance button; magnetic-card reader
- **Approx. count:** 96
- **Source:** HP-97 Owner's Handbook, Function Key Index and Programming Key Index (pp. 9–13) — hp/manuals/HP-97.pdf

## Notes
- Single-prefix design: only the gold `f` exists, so functions that are g/h-shifted on the HP-67 get dedicated keys or a single f-shift here.
- Program-compatible with the HP-67 (shares magnetic cards); adds thermal printing (PRINT x, PRINT SPACE/PRGM/REG/STACK) and the TRACE MAN/NORM print-mode switch.
- Conditional tests and DSZ/ISZ use skip-if-false logic: the following step runs only when the condition is true.
- Storage: primary R0–R9 and RA–RE plus I (index); protected secondary RS0–RS9 (also the statistics registers). 224-step program memory.
- The four PRINT f-shifts are silk-screened as a single "PRINT: SPACE—PRGM—REG—STACK" bracket beneath FIX/SCI/ENG/PRINT x.
