# HP-35 — Function Set

- **Access:** All functions are single physical keys — no shift/prefix. `arc` is an ordinary key pressed before sin/cos/tan to select the inverse. RPN entry with ENTER↑.
- **Approx. count:** 24 functions (excluding the ten digit keys)
- **Source:** HP-35 Operating Manual, Section 1 (pp. 11–20 of the booklet, PDF pp. 13–34) — hp/manuals/HP-35.pdf

## Arithmetic

| Function | Access | Description |
|----------|--------|-------------|
| + | key | Adds Y to X, result in X |
| − | key | Subtracts X from Y, result in X |
| × | key | Multiplies Y by X, result in X |
| ÷ | key | Divides Y by X, result in X |

## Powers & Roots

| Function | Access | Description |
|----------|--------|-------------|
| √x | key | Square root of the value in X |
| 1/x | key | Reciprocal of the value in X |
| x^y | key | Raises Y to the power of X (any real power, via logarithms) |

## Logarithms & Exponential

| Function | Access | Description |
|----------|--------|-------------|
| log | key | Common (base-10) logarithm of X |
| ln | key | Natural (base-e) logarithm of X |
| e^x | key | Raises e to the power X (natural antilogarithm) |

## Trigonometry

| Function | Access | Description |
|----------|--------|-------------|
| sin | key | Sine of X, angle in decimal degrees |
| cos | key | Cosine of X, angle in decimal degrees |
| tan | key | Tangent of X, angle in decimal degrees |
| arc | key (prefix) | Pressed before sin/cos/tan to give inverse trig; result in decimal degrees |

## Stack & Registers

| Function | Access | Description |
|----------|--------|-------------|
| ENTER↑ | key | Terminates entry and copies X up into Y (lifts the 4-level stack) |
| x⇄y | key | Exchanges the X and Y registers |
| R↓ | key | Rolls the stack contents down one position |
| CLx | key | Clears the X register (display) only |
| CLR | key | Clears the entire machine (stack and memory) |

## Memory

| Function | Access | Description |
|----------|--------|-------------|
| STO | key | Stores X into the single constant-memory register |
| RCL | key | Recalls the stored constant into X |

## Entry & Constants

| Function | Access | Description |
|----------|--------|-------------|
| CHS | key | Changes the sign of the mantissa or exponent being entered |
| EEX | key | Enter exponent — keys a power-of-ten exponent (scientific notation) |
| π | key | Enters the constant pi (3.141592654) |
| 0–9, · | keys | Digit and decimal-point entry |

## Notes
- First HP pocket scientific; every function has its own key, so there are no shifted functions.
- 4-level operational stack (X Y Z T); no LAST X register. Numbers outside 10^-2…10^10 auto-display in scientific notation; overflow shows all 9s, underflow shows zero.
- The HP-35 has no dedicated 10^x key; common antilogarithms are obtained via x^y with base 10.
