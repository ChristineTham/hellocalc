## Notes
- Command names come from Appendix D "Menu Map" and the "Key Index"; all softkey labels were legible (none marked `[?]`). Descriptions are paraphrased.
- **Differences vs HP-28C:** the 28S adds the **MEMORY** menu (directories: MEM, MENU, ORDER, PATH, HOME, CRDIR, VARS, CLUSR — replacing the 28C's small USER menu), **STAT** gains COMB and PERM, **STRING** gains →LCD and LCD→, **LIST** gains POS, and **PLOT** replaces DISP with DGTIZ. MODE and PRINT use single toggle commands (CMD, UNDO, LAST, ML, RDX,, TRAC) instead of the 28C's paired enable/disable commands.
- UNITS is a catalog and CATALOG/FORM/Solver-variables are interactive operations, so they are not enumerated as fixed command rows.
- PLOT's "Recall plot parameters" label is printed as `PPAR`, the reserved plot-parameter variable.
