# HP-67 — Function Set

- **Access:** three prefixes — `f` (gold) and `g` (blue), both printed below the key, and `h` (black) on the slanted key face; slide switches OFF–ON (power) and W/PRGM–RUN; magnetic-card reader
- **Approx. count:** 95
- **Source:** HP-67 Owner's Handbook and Programming Guide, Function Key Index and Programming Key Index (pp. 8–13) — hp/manuals/HP-67.pdf

## Prefix Keys

| Function | Access | Description |
|----------|--------|-------------|
| f | key | gold prefix; selects the gold function below a key |
| g | key | blue prefix; selects the blue function below a key |

## Notes
- Three prefixes f/g/h; gold (f) and blue (g) print below each key, black (h) on the key's front face.
- GTO/GSB accept label arguments A–E, a–e, 0–9, or (i); a small blue "f" on the GTO and SST keys denotes f-label addressing, not a separate function.
- Conditional tests and DSZ/ISZ use skip-if-false logic: the following step runs only when the condition is true.
- Storage: primary R0–R9 and RA–RE plus I (index); protected secondary RS0–RS9 (also the statistics registers). 224-step program memory.
- The layout file's printed R⇄P and H⇄H.MS f/g directions were corrected here from the manual and keyboard artwork: gold f performs rectangular→polar (→P) and decimal→H.MS (→H.MS).
- −x− and SPACE exist mainly for magnetic-card program compatibility with the printing HP-97.
