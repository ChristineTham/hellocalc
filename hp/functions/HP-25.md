# HP-25 — Function Set

- **Access:** two prefixes — `f` (gold, function above key) and `g` (blue, function on key's slanted front face); slide switches OFF–ON (power) and PRGM–RUN (program/run)
- **Approx. count:** 66
- **Source:** HP-25 Owner's Handbook, Function Key Index (pp. 5–6) plus programming-section keys — hp/manuals/HP-25.pdf

## Prefix & Clear

| Function | Access | Description |
|----------|--------|-------------|
| f | key | gold prefix; selects the gold function above a key |
| g | key | blue prefix; selects the blue function on a key's face |
| PREFIX | f | cancel a partially keyed prefix (f, g, STO, RCL, GTO) |
| CLX | key | clear the displayed X-register to zero |
| STK | f | clear all four stack registers to zero |
| REG | f | clear all storage registers to zero |
| PRGM | f | clear program memory |

## Notes
- Only two prefixes (f/g); there is no h shift.
- STO and RCL have no shifted functions; each takes a digit 0–7 or an arithmetic operator (register arithmetic).
- 8 storage registers R0–R7 (R3–R7 double as statistics registers); 49-step program memory.
- Conditional tests use skip-if-false logic: the following step runs only when the test is true.
- The printed Function Key Index (pp. 5–6) covers RUN-mode keys only; programming keys (SST, BST, GTO, R/S, PAUSE, NOP, conditionals) are documented in the programming section.
