# HP-25 — Keyboard Layout

- **Display:** Red LED; 8-digit mantissa + sign and 2-digit exponent + sign (10-digit scientific notation display, e.g. `-1.2345678-25`)
- **Prefix/shift keys:** `f` = gold (function printed in gold ABOVE the key), `g` = blue (function printed in blue on the slanted lower face of the key)
- **Logic / stack:** RPN 4-level (X Y Z T) + LAST X
- **Slide switches:** OFF–ON (power); PRGM–RUN (program/run mode)
- **Source:** HP-25 Owner's Handbook — Function Key Index (pp. 5–6) and the "HP-25 Memory" labeled keyboard diagram (rendered page p009) — hp/manuals/HP-25.pdf

## Notes
- Two-prefix scheme only (no `h`). Gold `f` functions are silk-screened ABOVE each key; blue `g` functions are on the slanted front face BELOW each key legend.
- Row 3 carries a "CLEAR" bracket over the three gold f-shifts PRGM / REG / STK (clear program, clear registers, clear stack).
- Fully-merged keys STO and RCL have no shifted functions of their own; STO/RCL take a digit 0–7 (storage register) or an arithmetic operator (register arithmetic).
- Storage: 8 registers R0–R7. Program memory: 49 steps.
- Physical grid: rows 1–2 are five keys wide; rows 3–7 are four keys wide (ENTER↑ is double-width in row 3).
