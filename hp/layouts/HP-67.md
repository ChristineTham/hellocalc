# HP-67 — Keyboard Layout

- **Display:** Red LED; up to 10-digit mantissa + sign and 2-digit exponent + sign (scientific display, e.g. `-1.234567890-67`)
- **Prefix/shift keys:** `f` = gold, `g` = blue, `h` = black. Gold (f) and blue (g) functions are printed on the calculator face BELOW each key; black (h) functions are printed on the slanted front face of the key itself.
- **Logic / stack:** RPN 4-level (X Y Z T) + LAST X
- **Slide switches:** OFF–ON (power); W/PRGM–RUN (write-program / run mode)
- **Card reader:** Magnetic-card slot below the display (right of the OFF–ON switch); card functions W/DATA and MERGE (f/g of ENTER↑)
- **Source:** HP-67 Owner's Handbook and Programming Guide — Function Key Index (pp. 8–12) and the "The HP-67" labeled keyboard diagram (rendered page p013) — hp/manuals/HP-67.pdf

## Notes
- Three-prefix scheme f/g/h. On this diagram: **gold = f** and **blue = g** are both printed on the panel below the key; **black = h** is printed on the slanted front face of the keycap.
- GTO and SST print "GSB f" and "LBL f" — gold GSB / LBL (f-shift) followed by a small blue "f". The blue "f" denotes label addressing (GSB/LBL accept program-label arguments, including the f-labels a–e); it is not an independent g-shifted function.
- Compound labels rendered with a gold base word and a blue extension share one key: SIN/SIN⁻¹ (f/g), DSZ/DSZ (i), ISZ/ISZ (i), and the two-way conversions R⇄P, D⇄R, H⇄H.MS. Exact f-vs-g direction for the conversion pairs is inferred from print color (gold left = f, blue right = g).
- Keys A–E are user-definable; their default (unshifted) RUN-mode functions 1/x, √x, y^x, R↓, x⇄y are silk-screened on the panel just above the top key row.
- The R/S / SPACE / −x− and similar labels exist for magnetic-card program compatibility with the printing HP-97 (on the HP-67 the print commands act as no-ops / pauses).
- Storage: primary R0–R9, RA–RE, I (index); protected secondary RS0–RS9. Program memory 224 steps.
- Physical grid: rows 1–3 are five keys wide; rows 4–8 are four keys wide (ENTER↑ is double-width in row 4).
