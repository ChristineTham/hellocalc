# HP-50g — Keyboard Layout

- **Display:** Dot-matrix graphing LCD, 131 × 80 pixels (softkey menu labels shown along the bottom row of the screen)
- **Shift keys:** Left-shift (white/on-key, key (8,1)) prints its function in white above-left of each key; right-shift (orange, key (9,1)) prints its function in orange above-right of each key; separate ALPHA key (key (7,1)) selects the A..Z letter printed to the right of the primary legend on each key
- **Logic / stack:** RPL with a dynamic, effectively unlimited stack (also has an algebraic entry mode)
- **Menu system:** Six softkeys — the F1–F6 keys (row 1) — map to the on-screen menu labels; NXT/PREV page through longer menus
- **Source:** HP 50g graphing calculator user's guide — "Introducing the calculator's keyboard", page 1-11 (PDF page 40); Appendix B, page B-1 — hp/manuals/HP-50g.pdf

## Notes
- Each key can carry up to five functions: primary, white left-shifted, orange right-shifted, ALPHA letter, and (for softkeys) the on-screen menu label.
- The four arrow/cursor keys (▲ ◄ ► ▼) form a diamond cluster on the right side of the keyboard spanning the space of rows 2–3 (columns 4–6); they also take shifted functions in use, not silkscreened on this diagram.
- Row 1 keys F1–F6 are the menu softkeys tied to the bottom row of the display.
- Digit keys (0–9) carry no ALPHA letter; letters A–Z are assigned to the function/operator keys as shown.
- The left-shift key is white/on-key colored (key (8,1)); the right-shift key is orange (key (9,1)); a dedicated ALPHA key (key (7,1)) enables letter entry.
