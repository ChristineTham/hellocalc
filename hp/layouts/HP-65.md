# HP-65 — Keyboard Layout

- **Display:** Red LED, 15 positions (10-digit mantissa with sign + 2-digit exponent with sign); DSP-selectable display format.
- **Prefix/shift keys:** Three prefixes — `f` (gold) selects the gold legend printed ABOVE each key; `f⁻¹` (gold) selects the inverse of that gold function (e.g. f⁻¹ SIN = SIN⁻¹); `g` (blue) selects the blue legend printed BELOW each key.
- **Logic / stack:** RPN, 4-level operational stack (X Y Z T) + LAST x register (g LST X). Fully programmable (100 steps) with magnetic-card storage.
- **Slide switches:** OFF–ON power switch; W/PRGM–RUN mode switch (both in a row above the keyboard).
- **Card reader:** Magnetic-card slot ("Window") along the top of the keyboard; cards are passed through the lower-right slot to read/record programs. No dedicated card-reader keys — programming uses LBL, GTO, RTN, SST, R/S, DEL, and the user keys A–E.
- **Source:** HP-65 Owner's Handbook (July 1974), labeled keyboard illustration, page 4 — PDF page 7 — hp/manuals/HP-65.pdf

## Notes
- Lower block layout follows the HP-35/45 pattern: left column of arithmetic operators (−, +, ×, ÷) beside a 3-wide numeric keypad; ENTER↑ spans the two leftmost columns of row 4.
- Three prefix keys give each physical key up to three functions: primary (white), gold `f`/`f⁻¹` (printed above), and blue `g` (printed below).
- The five top-row keys A–E are user-definable program keys; with `f` they act as 1/x, √x, y^x, R↓, x⇄y respectively.
- Manual callouts group keys as: Program Control Keys (A–E), Gold Prefix Keys (f, f⁻¹), Blue Prefix Key (g), Arithmetic Keys (−, +, ×, ÷), plus the OFF-ON and W/PRGM-RUN switches and the card-reader "Window".
