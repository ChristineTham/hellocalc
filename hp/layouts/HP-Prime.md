# HP-Prime — Keyboard Layout

- **Display:** Color LCD touchscreen, 320 × 240 pixels; bottom line of the screen is a context-sensitive touch-button menu
- **Shift keys:** Single **Shift** key (blue) + separate **ALPHA** key (orange); each physical key carries a primary legend (white), a blue shifted function (lower-left), and an orange alpha character (lower-right)
- **Logic / stack:** Configurable — algebraic (default), RPN, and textbook entry modes
- **Menu system:** On-screen context-sensitive touch-button menu (softkeys along the bottom of the touchscreen); apps launched from the Apps key
- **Source:** HP Prime Graphing Calculator user guide, Edition 1 (April 2006 imprint), "The keyboard", pages 7–8 (PDF pages 57–58) — hp/manuals/HP-Prime.pdf

## Notes
- Modern touchscreen graphing calculator: the 320 × 240 color LCD is fully touch-sensitive, and the bottom screen row is a context-sensitive touch-button (softkey) menu operated by tapping.
- A rocker/scroll wheel sits at the top center for cursor movement, flanked by the app/view keys (Apps, Symb, Plot, Num, Home, and Help, View, Menu, Esc, CAS).
- Each key has three functions: primary (white), Shift function (blue, lower-left), and ALPHA character (orange, lower-right). Only one Shift key (blue) plus a dedicated orange ALPHA key.
- Several upper keys carry glyph/icon faces (Home = house icon; Symb shows a boxed "x"); the row-1 keys 2–3 of the main pad show template/toolbox icons rather than text — described in brackets.
- Illegible shift legends marked [?]: the "( )" key shift, and the "9" key shift row (list/logic symbols).
- Del key and Enter key have no alpha character; Enter is a double-width key.
