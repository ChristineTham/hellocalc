# HP-28S — Keyboard Layout

- **Display:** dot-matrix LCD (right panel); shows up to 4 stack/display lines plus a menu-label row and a top annunciator row
- **Prefix/shift keys:** single red shift key (blank red key on right keypad, row 2 col 1); all second functions are printed in red — the red menu names above the left-keypad letter keys and the red legends above the right-keypad keys
- **Logic / stack:** RPL with a dynamic (unlimited-depth) stack; the display shows 4 levels but the stack grows as needed
- **Source:** HP-28S Owner's Manual, ch. 1 "Getting Started", keyboard illustrations pp. 26–27 (PDF p. 28–29) — hp/manuals/HP-28S.pdf

## Notes
- **Clamshell / two keypads:** left panel is the alpha + menu-selection keyboard; right panel is the numeric + function keyboard with the LCD and the 6 softkey (menu) keys below the display.
- **Single shift:** the HP-28S has only ONE shift key (red); all second functions are printed in red. No second-color shift.
- **Differences from HP-28C:** left keypad row 2 gains MEMORY (I) and STAT (K) menus (blank on the 28C), C is labelled COMPLX and J is ALGBRA. On the right keypad, SOLV's shift is PLOT and USER's shift is CUSTOM (on the 28C these were STAT and PLOT respectively). Bottom-right α key shift is MENUS (28C: α LOCK). The − key shift shows √x.
- **Menu softkeys:** the 6 blank keys under the display are redefined by menu labels on the bottom LCD line (e.g. SIN ASIN COS ACOS TAN ATAN). NEXT/PREV page through multi-row menus.
- **Annunciators (top of display):** busy (○), shift (↑), α (alpha), ((•)) I/O-print, low-battery, (2π) radians, and a printer/I/O icon.
- All legends legible; none marked [?]. The row-2 mode key (◄▶) primary legend is a graphic symbol rather than text.
