# HP-35s — Keyboard Layout

- **Display:** Two-line dot-matrix LCD (top line for the entered expression, lower line for the result), with an annunciator row (◄l l► ALG RPN EQN GRAD 0 1 2 3 4 A..Z PRGM HEX OCT BIN HYP ▲▼◄►)
- **Shift keys:** Left-shift (yellow, prints the function above each key); right-shift (blue, prints the function on the bottom-left of each key); no separate ALPHA key — letters (blue A..Z in the bottom-right of most keys) are typed directly when the A..Z annunciator is active
- **Logic / stack:** RPN 4-level stack + LAST X (also selectable ALG/algebraic mode)
- **Menu system:** No softkey row; menus (MODE, DISPLAY, catalogs, etc.) navigate with the cursor keys
- **Source:** HP 35s scientific calculator user's guide, Edition 1, page 1-2 (PDF page 18) — hp/manuals/HP-35s.pdf

## Notes
- Three functions per key: face legend, yellow left-shifted (printed above), blue right-shifted (printed on the bottom-left); most keys also carry a blue A..Z letter in the bottom-right for alpha entry.
- Cursor cluster (▲ ◄ ► ▼) sits at the top-right, occupying the space of rows 1–3, columns 5–6. Its left-shifts read FLAGS (▲), DISPLAY (◄), CONST (►), MEM (▼).
- The C key doubles as ON (power on, printed below) and its left-shift is OFF.
- Voyager-style body; keys arranged in the classic HP scientific grid.
- "ab/c" fraction-display label is silkscreened below the decimal-point key rather than on a key.
