# HP-49G — Keyboard Layout

- **Display:** Dot-matrix LCD, 131 × 64 pixels (softkey menu labels shown along the bottom row of the screen)
- **Shift keys:** Left-shift key and right-shift key (the two unlabelled keys that begin the "4" row and the "1" row) print their function above-left and above-right of each key; a dedicated ALPHA key selects the letter A–Z. NOTE: this Advanced User's Guide is a monochrome scan and does not convey the shift-key colours.
- **Logic / stack:** RPL — dynamic unlimited object stack (also has an algebraic entry mode)
- **Menu system:** 6 softkeys (top row F1–F6) mapped to on-screen menu labels; NXT/PREV page through longer menus
- **Source:** HP 49G Graphing Calculator Advanced User's Guide (Version 1) — keyboard illustration on the title page, PDF page 3 (this guide has no OCR text layer and no full-page keyboard diagram beyond the title-page image; layout cross-checked against the near-identical HP 50g faceplate) — hp/manuals/HP-49G.pdf

## Notes
- The four cursor keys (▲ ◄ ► ▼) form a diamond on the right side of the keyboard spanning rows 2–4; shifted cursor icons (page-up/down, begin |◄ / end ►|) are silk-screened around the diamond.
- ENTER is the bottom-right key (unlike the HP-48SX/48G, where ENTER is a wide key in the upper number block).
- The two blank shift keys occupy the left column of the "4" row (left-shift) and "1" row (right-shift); the ALPHA key is the left key of the "7" row.
- Row-4 primaries differ from the later HP 50g: the 49G has a **Cα** (catalog) key where the 50g has EVAL, and SYMB's right-shift here is EVAL (CAT on the 50g).
- Several small legends were read from a low-resolution monochrome title-page image; the relational-operator and math shifts (rows 5–6) and the digit-key application labels (rows 7–9) were confirmed against the essentially identical HP 50g faceplate.
- Digit keys carry no ALPHA letters; letters A–Z are assigned to the softkeys and function/operator keys.
