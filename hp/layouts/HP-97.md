# HP-97 — Keyboard Layout

- **Display:** Red LED; up to 10-digit mantissa + sign and 2-digit exponent + sign (e.g. `1.234567890 97`). Desktop **printing** model — adds a thermal strip printer (with paper-advance push-button) above the keyboard.
- **Prefix/shift keys:** `f` = gold **only**. The HP-97 uses a SINGLE gold `f` prefix (max two functions per key: white primary legend on the keycap + gold f-shift printed below the key). It does NOT use blue `g` or black `h` prefixes (unlike the HP-67).
- **Logic / stack:** RPN 4-level (X Y Z T) + LAST X
- **Slide switches:** OFF–ON (power); PRGM–RUN (program/run mode); TRACE: MAN–NORM (print-mode select). Plus a paper-advance push-button.
- **Card reader:** Magnetic-card slot; card functions WRITE DATA (f of 0) and MERGE (f of .)
- **Source:** HP-97 Owner's Handbook — "The HP-97" labeled keyboard diagram (rendered page p010) and Function Key Index / Programming Key Index (pp. 9–13) — hp/manuals/HP-97.pdf

## Notes
- **Single-prefix design:** only the gold `f` prefix exists; every key shows at most a white primary legend and one gold f-shift below it. Because the desktop keyboard has more room than the HP-67 pocket unit, functions that are g/h-shifted on the HP-67 (x², √x, SIN⁻¹, etc.) are given their own dedicated keys or a single f-shift here.
- Right block R1: the four gold f-shifts are printed as a single "PRINT: SPACE — PRGM — REG — STACK" bracket beneath FIX/SCI/ENG/PRINT x, i.e. f+FIX = PRINT SPACE, f+SCI = PRINT PRGM, f+ENG = PRINT REG, f+PRINT x = PRINT STACK.
- Keys 0–9, the decimal point, and DSP are white; all other keys are gold/tan with white primary legends. The `+` key is double-height; `ENTER↑` and `0` are wide keys.
- Functionally program-compatible with the HP-67 (shares magnetic cards); the HP-97 adds thermal printing (PRINT x, PRINT SPACE/PRGM/REG/STACK, TRACE MAN/NORM mode).
- Storage: primary R0–R9, RA–RE, I (index); protected secondary RS0–RS9. Program memory 224 steps.
