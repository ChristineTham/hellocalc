# HP-48G — Keyboard Layout

- **Display:** Dot-matrix LCD, 131 × 64 pixels (softkey menu labels shown along the bottom row of the screen)
- **Shift keys:** Left-shift = **purple** (◀ key — functions printed in purple above-left of each key); right-shift = **green** (▶ key — functions printed in green above-right); ALPHA = **white** (α key — selects the white capital letter at the lower-right of each key). (Stated on pp.1-4/1-5.)
- **Logic / stack:** RPL — dynamic unlimited object stack
- **Menu system:** 6 softkeys (top row A–F) mapped to on-screen menu labels; NXT/PREV page through longer menus
- **Source:** HP 48G Series User's Guide (Edition 8) — "The Keyboard and Display: Organization of the Keyboard", pp.1-4 to 1-7 (PDF pp.18–21); application list pp.1-6/1-7; "Math Functions on the Main Keyboard" pp.12-1/12-2 (PDF pp.143–144) — hp/manuals/HP-48G.pdf

> This User's Guide contains **no full keyboard illustration** — only a partial diagram (rows 3–7) on p.1-5, plus the application list and the Chapter 12 math-function tables. The HP 48G shares the **identical physical keyplate and primary legends** with the HP 48SX; the differences are the shift colours (purple/green vs. the SX's orange/blue) and reassigned second functions (notably the application launchers, which are **right-shift/green** on the 48G). Cells below that this guide does not document are marked `[?]`.

## Notes
- **Six function layers per key** (p.1-4): primary; left-shift (purple, above-left); right-shift (green, above-right); ALPHA (white letter, lower-right); plus the softkey menu label for row-1 keys.
- **Twelve application keys** (right-shift/green launches the application; the *same* key's left-shift/purple opens that application's companion **command menu** — p.1-6/1-7): CHARS, EQ LIB, I/O, LIBRARY, MEMORY, MODES, PLOT, SOLVE, STACK, STAT, SYMBOLIC, TIME. Positions verified in the grid for I/O (PRG), MODES (CST), MEMORY (VAR), LIBRARY (▲), SOLVE (7), PLOT (8), SYMBOLIC (9), TIME (4), STAT (5) and STACK (2). The physical keys for **CHARS** and **EQ LIB** are not diagrammed in this guide → marked `[?]`.
- Math-key shifts in rows 4 are confirmed by the Chapter 12 "Math Functions on the Main Keyboard" tables (ASIN/ACOS/ATAN, x²=SQ, ˣ√y=XROOT, 10ˣ=ALOG, LOG, eˣ=EXP, LN); the right-shift calculus symbols (∂ ∫ Σ) follow the 48-series faceplate and are not in those tables.
- ENTER is a double-width key in row 5 (left side); the backspace/DROP key is the rightmost key of row 5. `+` is the bottom-right key.
- ON doubles as ATTN (attention/cancel) while on.
- Rows 2–7 primary legends and A–Z ALPHA assignments match the HP 48SX faceplate; the partial diagram on p.1-5 confirms rows 3–7 primaries (′ STO EVAL ◄ ▼ ► / SIN COS TAN √x yˣ 1/x / ENTER +/− EEX DEL ← / α 7 8 9 ÷ / ◄ 4 5 6 ×).
