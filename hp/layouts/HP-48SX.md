# HP-48SX — Keyboard Layout

- **Display:** Dot-matrix LCD, 131 × 64 pixels (stated as "dot matrix" on p.25; the 4-line stack + softkey menu-label row are shown on screen)
- **Shift keys:** Left-shift = orange (▤ key, prints the function above-left of each key); right-shift = blue (▤ key, prints the function above-right); ALPHA = white (α key, selects the white letter at the lower-right of many keys)
- **Logic / stack:** RPL — dynamic unlimited object stack
- **Menu system:** 6 softkeys (top row A–F) mapped to on-screen menu labels; NXT/PREV (◀ shift) page through longer menus
- **Source:** HP 48SX Owner's Manual (Vol. I), "1: Getting Started — Introducing the Keyboard", printed pages 25–26 (PDF pages 29–30) — hp/manuals/HP-48SX.pdf

## Notes
- Keyboard illustration (printed p.26) labels ~49 keys. The six top-row keys (ALPHA A–F) are blank-faced softkeys that map to the on-screen menu labels along the bottom of the display.
- Three shift layers per key: left-shift (orange, above-left), right-shift (blue, above-right), and ALPHA (white letter, lower-right of many keys). Per p.25: "left-shift activates the orange key definitions above and to the left; right-shift activates the blue key definitions above and to the right; alpha activates the white alphabetic definitions to the lower right."
- Cursor cluster: ◄ ▲ ▼ ► — the up-arrow ▲ sits in row 2 (col 5) and ◄ ▼ ► sit in row 3 (cols 4–6). Their left-shifts are LIBRARY / GRAPH / REVIEW / SWAP.
- ENTER is a double-width key in row 5 (left side); the backspace/DROP key (◄) is the rightmost key of row 5.
- ON at lower-left doubles as ATTN (attention/cancel) while the calculator is on; left-shift+ON = CONT (continue), right-shift+ON = OFF.
- Keys 2 and 3 (row 8) sit under a "LAST" bracket → LAST STACK, LAST ARG, LAST CMD, LAST MENU.
- Digit keys carry no ALPHA letters; the A–Z letters are assigned to the softkeys and the function keys as shown.
