# HP-19B (Business Consultant II) — Keyboard Layout

- **Display:** dot-matrix LCD. The manual's Figure 1-1 labels three text lines — line 1
  and line 2 (history / results / messages) and **line 3, the *calculator line*** (also the
  edit line) — above a **6-label menu (softkey) row** and a top **annunciator row**.
- **Prefix/shift keys:** a single **orange (gold) shift key** (blank orange key, top-left of
  the right-hand keypad). Second functions are printed in **gold** above/below the keys; the
  `▲` (shift) annunciator lights when it is active. A separate **α (alpha)** mode activates the
  left-hand alphabetic keyboard (the `α` annunciator lights).
- **Logic / stack:** **Algebraic** (chain entry with an `=` key and parentheses). It is **not**
  RPN — the calculator line evaluates left-to-right regardless of operator (Solver uses full
  algebraic precedence). Lines 1–2 form a scrollable *history*, but there is no RPN X/Y/Z/T
  stack. (The later **HP-19BII** adds a selectable RPN mode; the plain 19B is algebraic only.)
- **Clamshell:** two hinged panels. **LEFT panel = the alphabetic keyboard** (A–Z + gold
  special characters) used to type Solver equations, TEXT and names, plus the printed
  quick-reference/menu-map overlay. **RIGHT panel = the main calculator** — the LCD, the six
  menu softkeys, and the numeric / function / edit keys (including `INPUT`, `STO`, `RCL`, the
  digit pad, operators, scroll arrows, `ON`, and the shift key).
- **Source:** *HP-19B Owner's Manual* (Reorder 00019-90012, English, 6/88) —
  cover device photo (PDF p.1); Figure 1-1 "The Display" (manual p.21 / PDF p.27); Table 1-1
  "Alphabetic Editing Keys" (p.27 / PDF p.33); Table 1-2 "The MAIN Menu" (p.29 / PDF p.35);
  Figure 1-5 "A Menu Map" (p.30 / PDF p.36); Appendix C "Menu Maps" (pp.306-313 / PDF
  pp.312-319). Key legends read from the cover photo — hp/manuals/HP-19B.pdf.

## Notes

- **Two flaps, not two keypads of equal role.** Unlike the task's template, on the 19B the
  display, six softkeys, `INPUT`, `STO`/`RCL`, digits, operators, scroll arrows, `ON` and the
  shift key are **all on the right (main) panel**. The **left flap holds only the alphabetic
  keyboard** (A–Z + gold special characters) plus the printed reference overlay.
- **Single orange shift.** There is one prefix key (blank, orange, right panel row 1 col 1); all
  second functions are printed in gold. The `▲` annunciator shows shift is pending.
- **Algebraic, not RPN.** The 19B has no X/Y/Z/T stack; entries use `=`, `( )` and chain logic.
  RPN is a 19BII-only feature.
- **MAIN menu** = `FIN  BUS  SUM  TIME  SOLVE  TEXT` (confirmed by Figure 1-1, Table 1-2 and
  Figure 1-5). Reach it with **shift + EXIT (MAIN)**. `EXIT` alone backs up one menu level.
  A **`MORE`** softkey pages between label sets when a menu has more than six items.
- **Editing keys (Table 1-1).** In alpha/edit mode the active keys are: `◄` backspace (erase
  left), shift+`CLEAR` (clear the calculator line), cursor `◄`/`►` (move one char — believed to
  be the `(` / `)` keys), shift+cursor (jump to first / last char), and `INS` / `DEL` (insert /
  delete a character). The exact physical key/shift assignment of the cursor, `INS` and `DEL`
  was not legible in the photo and is marked `[?]` above.
- **Annunciators (Figure 1-1), left→right:** `▲` shift active · `α` alphabetic keys active ·
  `((•))` past-due appointment · battery (low batteries) · `(2π)` radians mode · printer icon
  (sending to printer).
- **`[?]` cells / uncertainty.** The manual is an image-only scan with **no flat keyboard
  diagram**; the sole keyboard image is the cover device photo, in which a hand and the spiral
  binding obscure the lower-left of the alphabetic flap and several gold special characters.
  Letter identities (A–Z, alphabetical 6-wide grid) are certain from the visible keys
  (C D E F / I J K L / P Q R / W X) and sequence; the unread **gold special characters** and the
  **row-5 typing keys** are marked `[?]` rather than guessed. Right-panel legends and shifts are
  all legible.
- **Column alignment caveat.** The right-panel rows above are grouped functionally; because the
  only photo is oblique, exact column alignment between the top function rows and the numeric
  block is approximate, but the key set and gold shifts are as read.
