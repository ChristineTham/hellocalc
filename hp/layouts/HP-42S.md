# HP-42S — Keyboard Layout

- **Display:** two-line, 22-character alphanumeric dot-matrix LCD with adjustable contrast; top line can show 6 menu labels; 7 annunciators above the display
- **Prefix/shift keys:** single shift key (blank orange/gold key, filled-square symbol ■, row 6 col 1); the shifted function is printed in orange ABOVE each key
- **Logic / stack:** RPN 4-level (X Y Z T) + LAST X
- **Source:** HP-42S Owner's Manual, keyboard diagram inside front cover (PDF p. 2); ch. 1 "Getting Started" pp. 18–22 — hp/manuals/HP-42S.pdf

## Notes
- **Pioneer-series single-shift RPN scientific.** One orange/gold shift key; shifted functions printed in orange above each key. Over 350 built-in functions reached via menus, the function CATALOG, and XEQ.
- **Menu softkeys:** the top row of 6 keys is redefined by menu labels shown on the top display line. Selecting a menu (e.g. shift-PROB) relabels these keys; ▲/▼ page multi-row menus; EXIT leaves the menu. Application menus (BASE, MATRIX, SOLVER, STAT, ∫f(x)) and function menus (CATALOG, CLEAR, CONVERT, CUSTOM, DISP, FLAGS, MODES, PGM.FCN, PRINT, PROB, TOP.FCN) are all menu-driven.
- **CUSTOM menu / ASSIGN** let the user map functions onto the menu keys.
- **Annunciators (7, top of display):** ▼▲ (multirow menu active), shift (↴), printer (sending to printer), ((•)) busy, low-battery, RAD (radians), GRAD (grads). DEG is the default and has no annunciator.
- **Stack:** classic 4-level RPN (X, Y, Z, T) with a LAST X register; R↓ rolls the stack, x⇄y exchanges X and Y.
- **ALPHA menu** (shift-ENTER) is an on-screen extension of the keyboard for typing characters not on the keys.
- All legends legible; none marked [?].
